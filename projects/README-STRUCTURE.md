# 首页结构规范

## 页面布局顺序

1. **导航栏** (固定顶部)
   - HOME / PROJECTS / LIFE / GAMING
   - Contact 不在导航栏体现

2. **首页交互区**
   - Glitch 标题 (Liufei' Cyber World)
   - Terminal (紧接标题后)
   - Info Panel (avatar + 介绍文字)
   - Skills Grid

3. **Life 板块**

4. **Projects 板块**

5. **Contact** (仅在 footer 体现)

## Info Panel 规范

- **宽高动态调整**：跟随内容自动撑开
- **最小高度**: 200px
- **Avatar 尺寸**: 140x140px
- **对齐方式**: flex-start (确保内容完整显示)
- **overflow**: visible (防止裁剪)
