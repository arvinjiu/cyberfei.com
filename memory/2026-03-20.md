### 技术要点
- **相对路径 vs 绝对路径**：部署到不同服务器时，相对路径更灵活
- **EmulatorJS 配置**：
  - `EJS_pathtodata`：核心文件路径
  - `EJS_gameUrl`：ROM 文件路径
  - `EJS_core`：模拟器核心名称
- **防重复加载**：通过 `ejs-loader` 脚本标签检测

### 修复 ROM 选择器闪烁问题
**问题**：
1. 选择模拟器前 ROM 列表应保持禁用
2. 选择模拟器后 ROM 列表应显示"请选择 ROM"
3. 切换模拟器时 ROM 选择器快速闪烁，显示不正常

**解决方案**：
- 在 `coreSelect` 的 `change` 事件中，先禁用 ROM 选择器并显示"正在加载..."
- 加载完成后才显示"请选择 ROM"并决定是否启用
- 避免旧选项残留导致的闪烁

**代码改动**：
```javascript
// 切换模拟器时先清空并禁用
romSelect.disabled = true;
romSelect.innerHTML = '<option value="" selected disabled>正在加载 ROM 列表...</option>';
loadRomList(core);
```
